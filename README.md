# 扫雷 · raylib 经典 Windows 风格版

用 C 语言 + [raylib](https://www.raylib.com/) 写的扫雷小游戏，界面模仿 Windows 95 / XP 经典扫雷：
灰色立体边框、红色 LED 计数器、黄色笑脸按钮，左键翻开、右键插旗、踩雷后亮出全部地雷。

## 功能

- 9 × 9 棋盘，10 颗雷
- 左键翻开 / 右键插旗（顶部 LED 显示剩余雷数）
- 点笑脸或按 `R` 键重开
- 计时器；笑脸随状态变化（正常 / 按下 / 哭脸 / 墨镜）
- 胜负结算横幅
- 原控制台版的三个核心算法（布雷 / 展开 / 判定）原样保留

## 代码结构

| 文件 | 作用 |
|---|---|
| `sao_lei.h` | 所有函数声明 + 各源文件共享的数据声明（`extern`） |
| `sao_lei_core.c` | 核心逻辑：布雷、空白区递归展开、胜负判定（**不含任何图形库**） |
| `sao_lei_ui.c` | 全部 raylib 内容：窗口、字体、绘制、鼠标交互、主循环 |
| `sao_lei.c` | 主文件，只有 `main()`，用 `extern` 调用另外两个源文件里的函数 |
| `sao_lei_console_backup.c` | 最初的控制台版本备份（未加入工程，仅作存档） |

## 编译运行

1. 下载 raylib（6.0，MSVC x64 版）并解压，工程里默认放在 `E:\UI\raylib`
2. 用 Visual Studio 2026 打开 `Project3.slnx`，选择 `Release | x64`，直接“生成”
3. 生成的程序在 `Project3\x64\Release\Project3.exe`

> 如果 raylib 放在别的路径，请修改工程属性里的「附加包含目录」和「附加库目录」。

## 操作说明

| 操作 | 效果 |
|---|---|
| 鼠标左键 | 翻开格子 |
| 鼠标右键 | 插旗 / 取消旗 |
